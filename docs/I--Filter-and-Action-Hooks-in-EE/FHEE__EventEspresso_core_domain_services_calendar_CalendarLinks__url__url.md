# FHEE__EventEspresso_core_domain_services_calendar_CalendarLinks__url__url

Filters each "Add to Calendar" URL generated by the `CalendarLinks` service. The value is the unescaped URL (escape at output). Core returns an empty string for unknown provider keys, so this filter is also where a custom provider (added via `FHEE__EventEspresso_core_domain_services_calendar_CalendarLinks__providers__providers`) supplies its URL. Returning an empty string drops the link.

`FHEE__EventEspresso_core_domain_services_calendar_CalendarLinks__url__url`

**Found in:** `core/domain/services/calendar/CalendarLinks.php`

**Parameters:** `string $url`, `string $provider`, `EE_Datetime $datetime`, `EE_Event|null $event` (the event passed to `CalendarLinks::links()` or `url()`, if any; for `ics` a non-null event means the URL is the event-level, all-dates ICS file)

## Usage Example:

```php
function my_calendar_url(string $url, string $provider, EE_Datetime $datetime, ?EE_Event $event): string
{
    if ($provider === 'my_calendar') {
        return add_query_arg(
            ['start' => gmdate('Ymd\THis\Z', $datetime->start())],
            'https://calendar.example.com/add'
        );
    }
    return $url;
}
add_filter('FHEE__EventEspresso_core_domain_services_calendar_CalendarLinks__url__url', 'my_calendar_url', 10, 4);
```
